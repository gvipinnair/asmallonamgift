# Onam Surprise – Gowri 🌸

This version follows the uploaded sample-video feel: ruled notebook paper, black marker drawings, simple stick-figure animation, moving characters, speech bubbles, and a visible hand-drawn-story rhythm.

Flow:
1. Door opens and girl invites Gowri inside.
2. Mouse runs, cat chases, children play, Sadya is prepared.
3. Someone steps forward and compliments Gowri.
4. Mahabali raises his hand and flowers pop into the scene with an Onam wish.
5. Gowri is asked to enter the hall.
6. The real Gowri pookalam image is revealed and `gowri-voice.mp3` starts.
7. Postcard opens after the voice ends.

Assets:
- `assets/gowri-pookalam-face.png`
- `assets/gowri-voice.mp3`

Open `index.html` or deploy the folder to GitHub Pages.
